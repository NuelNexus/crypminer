Drop green-screen overlay videos here (.mp4/.mov/.webm), e.g. a like/subscribe animation on pure green (#00FF00).
When this folder has videos, the clipper picks one at random per clip and keys it over the lower third
instead of the built-in animated LIKE/SUBSCRIBE buttons. Only use overlays you are licensed to use
(your own, or ones marked free for commercial use with no attribution or Content ID).
